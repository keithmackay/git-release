# git-release

Prepares a local git project for public release on GitHub — adds an MIT license, verifies README/CHANGELOG/.gitignore, creates a GitHub remote if needed, sets the repo description and topics, applies branch protection requiring PRs, and cuts a tagged GitHub release.
